# ElastiqA

A phase vocoder — time stretching and pitch shifting that keep the two
independent — with the measurements to show it works.

`packages.txt` installs ffmpeg so compressed uploads (MP3, M4A) decode.
WAV works without it.

Built for a Signals and Linear Systems course. Source, tests, and the full
benchmark: https://github.com/USERNAME/elastiqa
